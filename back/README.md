# TheTipTop API

L’API est une application Symfony située dans `back/app`.

```powershell
cd back/app
composer install
php -S 127.0.0.1:8000 -t public public/index.php
```

La configuration locale se fait dans `.env.local` à partir de `.env.local.example`. Voir `back/app/README.md` pour les migrations et les tests.
